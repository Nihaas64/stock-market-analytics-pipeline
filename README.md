# Stock Market Analytics Pipeline

This project analyzes historical stock market data using Python, Databricks, and PySpark.

The goal of this project is to demonstrate a basic financial data analytics workflow including data ingestion, processing, and visualization.

## Features

- Fetch historical stock data using Yahoo Finance API
- Process financial datasets using PySpark in Databricks
- Calculate metrics such as average closing price and daily returns
- Visualize stock trends and compare multiple companies

## Technologies Used

- Python
- Databricks
- PySpark
- Pandas
- Matplotlib
- yfinance

## Companies Analyzed

- Apple (AAPL)
- Microsoft (MSFT)
- Nvidia (NVDA)
- Tesla (TSLA)

## Example Output

The project generates visualizations comparing stock price trends across companies.
